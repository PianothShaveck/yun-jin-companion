# 开始使用
## 安装
从 GitHub 发布页下载应用 ZIP，并解压整个文件夹。在 64 位 Windows 10/11 上打开 Windows.cmd。在 macOS 13 或更高版本上打开 Mac.command；如果提示安装 Python，请完成安装。Mac 应用安装在 /Applications。在 Linux 上安装受支持的 Python 和 python3-venv，然后运行 sh Linux.sh。安装程序使用独立环境，并保留已有的个人数据。
## 选择语言
首次启动时选择 Italiano、English 或 简体中文。在设置 → 语言中更改界面语言，下次启动时生效。指南会打开对应语言的文档。语音页面的语言单独控制朗读、问候和天气评论。
## 基本操作
双击云堇打开面板，右键打开菜单，拖动可移动她。菜单控制散步、跟随、动画、大小和透明度。自主散步与跟随鼠标可以分别启用。手动选择的动画会立即播放。
隐藏云堇只隐藏角色；工具、提醒和闹钟仍会运行。在 macOS 上，可通过菜单栏图标重新打开面板。全屏设置控制角色是否显示在全屏应用之上。从角色菜单退出会关闭应用；关闭面板只会隐藏面板。
## 快捷键
设置 → 快捷键可以设置按键、清除绑定或恢复默认值。Windows 和 macOS 支持全局快捷键；Linux 上仅在云堇窗口内生效。冲突的组合会被标出。快捷键可以控制工具、显示、语音、日程和闹钟。

# 笔记与提醒
## 笔记
新建可创建笔记，标题和正文会自动保存。导入支持剪贴板内容、文件和文件夹，也可以把文件拖到面板或角色上。打开会使用文件原来的应用。链接文件仍保存在原位置；移动后请更新笔记中的链接。剪贴板中捕获的图片会存入应用数据文件夹。
搜索可查找标题、正文和路径。朗读会读出当前笔记。笔记的 ⋯ 菜单提供保存和删除。删除笔记不会删除链接的文件。
## 使用 ChatGPT
在笔记中打开 ChatGPT，选择解释、翻译、审阅或提问，然后选择复制并打开。将准备好的请求粘贴到 ChatGPT。引用的文件需要自行添加；应用不会上传文件或自动发送请求。
## 提醒
新建提醒可以设置延迟，或指定日期和时间。快捷按钮可选择常用间隔。到期时可选择完成或10 分钟后。隐藏只关闭通知，不会完成提醒。提醒列表显示待办项目；已完成显示完成的项目。可通过相应控件编辑、推迟或删除。
语音和声音设置控制音频反馈。关闭音频后仍会显示文字通知。提醒需要应用保持运行，不能唤醒已经关机的电脑。

# 日历与闹钟
## 日程
选择日期，然后选择新建日程。填写标题、开始、结束和可选备注。全天事件的编辑器包含起止两天：周一至周二表示两天。提醒设置提前通知的时间；朗读提醒可为该日程开启语音。
可按天、周、月或年重复，设置间隔，以及截止日期或次数。修改或删除系列时选择仅此次或整个系列。每月31日会跳过没有31日的月份；2月29日只在闰年出现。从 Google 导入的时区会被保留；本地日程使用电脑时区。
## 导航与插图
箭头切换月份；今天返回当前日期。点击月份标题可选择月份和年份。键盘方向键选择日期，Enter 创建日程，Page Up/Down 切换月份，Home 返回今天。
每个月都有每日插图，同一年内顺序固定，不同年份会变化。打开插图可查看原图；尚未缓存的原图会按需下载。原图/预览标签说明当前显示的内容。点击鼠标或按 Esc 关闭。
## 闹钟
新建闹钟可设置时间、可选名称、重复、声音、语音和稍后提醒间隔。一次性闹钟响铃后会停用；重新启用会安排下一次。停止可结束响铃，稍后提醒会重新安排。声音最多持续一分钟，但通知会保留。
电脑休眠或应用重启后，只补发最近一次错过的提醒：闹钟在10分钟内，日程提醒在两小时内且日程尚未结束。更早的提醒仅保留在列表中，不会响铃。应用运行时，即使隐藏角色或开启专注，闹钟仍然有效。

# Google Calendar
## 连接与选择日历
Google 连接目前仅对已加入项目测试用户列表的账号开放。测试期间，Google 要求每 7 天重新连接一次；出现提示时，请使用重新连接账号。日程和待同步修改都会保留。
在日历中选择连接 Google Calendar。浏览器将打开：请选择 Google 账号并授权云堇连接。设置中也可以打开相同的连接选项。凭据保存在操作系统的钥匙串中；应用不会保存 Google 密码。
选择需要同步的日历。新日程设置默认保存位置。编辑日程时，可以选择日历或仅此设备。已有本地日程在手动指定日历前始终保留在本地。闹钟、笔记和闪卡不会上传到 Google Calendar。
## 多设备使用
在每台电脑上连接同一个 Google 账号，并选择相同日历。更改也会显示在手机的 Google Calendar 中。同步可立即刷新；本地编辑后和连接期间会定期自动同步。接收更改需要应用保持运行。
离线修改会保留，并在恢复连接后同步。不要为了重试上传而另建副本。账号 → 断开此设备只停止本设备的同步，不会删除 Google 中的事件。其他设备不受影响；重新连接同一账号会保留事件对应关系。
通过账号 → 管理 Google 授权可在Google中查看或撤销应用权限；撤销可能影响所有已连接设备。
## 冲突与只读事件
不同字段的修改可以合并。如果同一内容在两端发生不同修改，冲突页面提供使用本地、使用 Google 或保留两者。保留两者会保留 Google 共享版本，并创建一个独立的本地副本；该副本不会上传。
只读共享日历、不受支持的事件类型或重复规则不能在应用中修改。请使用在 Google Calendar 中打开进行管理。在云堇中编辑受支持字段时，会保留 Google 专有信息，例如参与者和地点。

# 学习与闪卡
## 创建与复习
新建牌组创建一个集合。添加卡片可选择正面/背面或填空。将问题和答案写在对应面。选中文字后选择填空，或使用 {{c1::文字}}；提示写为 {{c1::文字::提示}}。不同数字生成不同卡片，相同数字同时隐藏多个片段。不支持嵌套填空。
每面可包含文字及最多12个图片或音频附件，每个不超过32 MB。附件会复制到应用数据文件夹。预览查看效果；保存并添加继续创建下一张。编辑文字不会清除现有卡片的学习进度。
## 复习过程
学习显示问题；显示答案或空格键揭晓答案。用重来、困难、良好或简单评价记忆，也可按1–4。撤销上次回答恢复之前状态。短学习步骤可能需要等待下一张卡片。
牌组概览显示新卡、学习中和复习卡。搜索卡片可以查找和编辑笔记；暂停/恢复控制是否安排复习。删除卡片会删除该卡片及相关填空。归档牌组会将其移出当前学习列表，但保留数据；已归档牌组可恢复。
## 复习安排
FSRS 根据回答安排复习，并在历史足够时调整参数。参数改善不会直接移动已有到期日期。在牌组选项中关闭 FSRS 可使用传统间隔。
30天实际记忆率统计间隔至少一天的复习中成功记住的回答，不包含短学习步骤。目标记忆率越高，需要的复习越多。

# 学习设置与 Anki
## 牌组选项
目标记忆率默认为90%。每日新卡和复习上限默认不限；设为零会阻止开始该类新任务，但当天已经开始的学习步骤会继续。每日计数在本地时间04:00重置。
新卡步骤默认为10s 30s 1m 10m；遗忘后步骤为10s 30s 1m。用空格分隔：s为秒，m为分钟，h为小时，d为天。没有单位表示分钟。留空可让 FSRS 决定间隔。重来返回第一步，良好进入下一步，困难重复调整后的步骤，简单直接进入复习。
默认在复习中遗忘16次后，卡片会被标记为难记卡并暂停。可在牌组选项中调整阈值或关闭自动暂停。难记卡列表可查看这些卡片。
## 复习提醒
复习提醒与 Anki 控制偶尔出现的练习邀请：间隔90–150分钟，每天最多三次。从今天学习过的牌组中选择困难卡片，距离上次复习至少30分钟，且避免重复今天或昨天已显示的笔记。专注和其他活动期间不会打扰。复习打开最多三张卡片；今天不再提醒暂停当天邀请。
## Anki
启用包含 Anki 卡片，然后选择 Anki 配置或浏览到 collection.anki2，无需安装 Anki 插件。读取每15分钟更新一次，也可在 Anki 打开时工作；如果数据库正忙，请稍后重试或关闭 Anki。
练习选择今天学过牌组中的难记卡和最困难的10%卡片。不会修改 Anki 的回答或复习安排。支持具有可读静态内容的正反面和填空模板、本地图片及音频，不执行脚本。包含已暂停难记卡只影响练习，原卡片仍保持暂停。

# 音乐、计时与专注
## 节拍器
设置20–400 BPM并按开始。敲击测速根据点击估计速度。重音设置每几个拍子出现一次重音；音量独立于语音和角色音效。
渐变速度按指定步长和拍数间隔逐步达到目标速度。可选择最后一个间隔后继续或停止。停止结束播放。电脑休眠或音频设备发生错误后，请检查输出并重新按开始。
## 秒表
开始/暂停保留已用时间。计次同时记录单圈和总时间。重置清除计时和计次。复制将表格放入剪贴板；CSV可导出。正常关闭再打开应用后，已记录的时间仍然保留。
## 专注
选择时长并按开始；结束时会收到提醒。停止结束当前会话。专注会抑制可选的学习提醒，但不会关闭已安排的闹钟和日程提醒。节拍器和秒表仍是独立工具。
## 角色行为
散步、跟随鼠标和注视鼠标可分别设置。菜单提供手动动作和动画、个性、大小、透明度及屏幕选择。移回屏幕可找回移到可见范围外的角色。全部暂停停止角色活动；隐藏角色仍保留工具。

# 语音、声音与天气
## 语音
开启语音控制朗读输出。关闭后仍保留文字气泡、通知和动画。朗读使用输入文字或笔记；朗读剪贴板文字使用复制内容。停止会取消语音和气泡。长文字分段显示；每次可选取最多3,000个字符朗读。
Microsoft Edge提供声音、语速、音调和音量控制。Google Translate提供语言、慢速朗读和音量，由服务选择声音。无需API密钥。朗读文字会发送到所选在线服务，能否使用取决于该服务。已生成音频会缓存在本地。⋯ 菜单可清空缓存或恢复语音默认设置。
语音、音效和节拍器音量相互独立。静音1小时可暂时关闭角色声音。手动朗读会停止节拍器。自动朗读提醒有单独开关。
## 时间与天气
设置 → 时间与天气可分别启用启动问候、随时间变化的动画和天气反应。手动选择城市，不需要设备定位权限。选择城市后，导航中会出现天气。
天气页面显示当前估计、每日预报和小时详情。选择日期或小时查看温度、降水和风。刷新请求新数据；离线时仍显示已保存结果。时间使用预报地点的时区。天气数据来自 Open-Meteo，城市搜索使用 GeoNames。

# 数据、更新与帮助
## 备份与恢复
设置 → 备份导出数据库、捕获的图片、闪卡媒体和偏好设置。外部链接文件不会复制，请另行保存。数据文件夹可打开存储位置。
恢复前关闭云堇，保留当前数据文件夹的副本，再将备份中的 companion.sqlite3、attachments 和 study-media 解压到该文件夹。只能在应用关闭时替换数据库。恢复的日历数据仅保存在本地：Google凭据及同步对应关系不会恢复。检查恢复的日程后，再决定重新连接账号。
## 更新与卸载
自动更新约每两小时检查一次。阅读发布说明后，可选择稍后、跳过此版本或更新并重启。需要新依赖时，请使用发布包的安装程序。重启失败会恢复之前的程序。个人数据会保留，成功更新留下的旧安装包会自动清理。
卸载时先关闭应用并删除快捷方式；macOS还需删除 /Applications 中的应用。数据文件夹包含程序和运行环境。删除该文件夹前，请保留 companion.sqlite3、attachments 和 study-media，或导出备份。
## 故障排查
找不到窗口时，可使用系统托盘、菜单栏图标或面板快捷键。没有声音时，检查对应音量、静音状态和输出设备。语音失败时重试或切换服务。Anki正忙时关闭后重试。撤销Google授权后或收到重新授权提示时，请重新连接；待同步修改仍会保留。
重新运行安装程序可修复环境。如果问题持续，请查看数据文件夹中的 yun-jin.log；提交问题时不要附带个人笔记、数据库或凭据。应用关闭或电脑关机时，闹钟和提醒无法运行。
